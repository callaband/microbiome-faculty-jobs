About

Every day a GitHub Action reads public job-board feeds, keeps faculty positions that mention microbiome science, and labels each one by research area, rank, tenure status, institution type, research/teaching effort and review dates. It's an open project: anyone can submit a position, report a mislabel, or improve the filters in config/taxonomy.yaml. Institution types for US employers come from the U.S. Department of Education's IPEDS directory (Carnegie classification; PUI = master's or baccalaureate institution).
